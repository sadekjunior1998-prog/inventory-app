Inventory Management System

A Python-based inventory management application built with SQLite.

Features

- Manage product inventory
- Store data in an SQLite database
- Validate user input
- Generate inventory reports in CSV format
- Organize code into separate Python modules

Technologies

- Python
- SQLite
- CSV

Project Structure

- "main.py" — Application entry point
- "database.py" — Database operations
- "report.py" — Report generation
- "utils.py" — Utility functions and input validation
- "constants.py" — Shared constants
- ".gitignore" — Excludes local database and generated files

Getting Started

1. Install Python.

2. Download or clone this repository.

3. Run the application:
   
   "python main.py"

Purpose

This project demonstrates practical Python programming, database management, input validation, and automated report generation.
